# arduino-74hc595-binary-bit-manipulation
Description: Arduino projects exploring 74HC595 shift register, binary counters, number systems, bit shifting, circular shifts, and bit manipulation.
Arduino 74HC595 & Bit Manipulation

This repository contains the Arduino UNO programs I worked on while learning about number systems, the 74HC595 shift register, binary counting, and bit shifting.

What I Learned

- Number systems using Arduino
- Using the 74HC595 shift register to control LEDs
- Creating a binary counter with LEDs
- Logical left and right shifts
- Circular left and right shifts
- Binary bit flipper

Components Used

- Arduino UNO
- 74HC595 IC
- LEDs
- Resistors
- Breadboard
- Jumper wires

About This Practice

Through these programs, I got a better understanding of how binary numbers and bits work in Arduino. I also learned how the 74HC595 can help control multiple LEDs using fewer Arduino pins.

This is another step in my Arduino UNO learning journey, where I am learning embedded concepts by actually building and testing small programs.

Platform: Arduino UNO
Focus: Binary & Bit Manipulation • 74HC595 • Digital Electronics
